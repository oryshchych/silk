## Фаза 5 — Адмінка: замовлення й клієнти (1–1.5 тижня)

**Обсяг:**
- Список замовлень: фільтри, пошук по номеру / телефону / email / ТТН.
- Картка: позиції, редагування складу до відправки з перерахунком, дані доставки, лог `payment_events`, внутрішні примітки, повна історія.
- **ТТН Нової Пошти з адмінки** (`InternetDocument/save`), збереження номера, друк накладної та маркування.
- `orders.shipping_cost_actual` — реальна вартість доставки з відповіді НП. Без неї звіт маржинальності бреше.
- Workflow статусів кнопками, обов'язковий коментар при скасуванні.
- Повернення коштів.
- Клієнти: LTV, історія, улюблені розміри як агрегація покупок, сегменти, теги, експорт.
- Експорт замовлень для бухгалтерії.

**Критерії приймання:**
- [ ] ТТН створюється, зберігається, лист іде, трекінг відкривається
- [ ] Редагування складу оплаченого замовлення перераховує суму і пише в історію
- [ ] Повернення через API провайдера змінює `payment_status` і видно у звіті
- [ ] Картка клієнта показує розміри, виведені з покупок
- [ ] Список 10 000 замовлень відкривається за < 500 мс
