## 9. Безпека — модель загроз

| Загроза | Захист |
|---|---|
| Підміна ціни на клієнті | Сервер перераховує все з БД. Клієнт надсилає лише `variantId` + `quantity` |
| Повторне застосування промокоду | `promo_code_redemptions` з унікальними обмеженнями в БД |
| Race на останній одиниці | Атомарний conditional `UPDATE`, не read-then-write |
| Підробка вебхука | Перевірка підпису на raw body до парсингу |
| Дубль вебхука | `UNIQUE(provider, external_id)` |
| Доступ до адмінки | Auth.js + `middleware` + перевірка ролі **у кожному** server action. Не тільки в middleware |
| Витік `cost_price` | Ніколи не входить у публічні селекти. Окремий query-шар для адмінки |
| XSS через rich-text | DOMPurify на сервері перед збереженням і при рендері |
| Спам форм | Rate limit + Turnstile + honeypot |
| Витік секретів | Тільки серверні env. CI-крок `grep` по `.next/static` на патерни ключів |

`SECURITY.md` містить таблицю: кожна мутація → хто може викликати → де перевіряється. Оновлюється разом з кодом.
