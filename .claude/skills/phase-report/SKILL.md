# phase-report

1. Прочитай `docs/plan/CURRENT.md` і файл поточної фази `docs/plan/phase-NN-*.md`.
2. Для **кожного** критерію приймання визнач статус. `[x]` — лише якщо перевірено
   **виконанням**, з посиланням на команду / тест / коміт («`pnpm test:int` — 30/30»),
   не «написав тест».
3. Відхилення від плану — з `CURRENT.md` і git log; змінене рішення не ховати.
4. Сформуй звіт:

```
Фаза N завершена.            ← або «Фаза N: стан», якщо не всі пройдені
Критерії приймання:
  [x] критерій — як перевірено
  [ ] критерій — чому не виконано
Відхилення від плану: ...
Що потребує рішення людини: ...
```

5. Онови `docs/plan/CURRENT.md` (≤ 60 рядків) і закоміть.
6. **Зупинись.** Далі — лише після явного «переходь до фази N+1».
